# Materiale

Legg forelesnings-PDF-er, slides og egne skannede notater her. Undermapper er lov.

- Filene her blir **ikke** lastet opp til GitHub (se `.gitignore`). Grunner: opphavsrett og filstørrelse.
- Kjør etterpå: `uv run lag_kilder.py`. Da får du tekstversjoner i `kilder/pdf/` som Copilot, NotebookLM og Gemini kan lese.
- Er repoet ditt **privat** og du vil ha materialet i skyen? Slett de to `materiale/`-linjene i `.gitignore`.
